# Text-to-Speech
Mid-Term Group Project ( Text-to-Speech )

# Project Description:

This project is a simple Text-to-Speech (TTS) application built using Python and the Google Text-to-Speech (gTTS) library. The user pastes any text (such as from a document or PDF), and the app converts it into spoken audio. The result is saved as an .mp3 file, making it easy to listen to the content later. This tool is useful for students, visually impaired individuals, or anyone who prefers listening to reading.
